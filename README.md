# Desafio-Fullstack-Produtos

# 🚀 Projeto Prático - CRUD de Produtos (Fullstack)

Este repositório centraliza as instruções e os links para acesso aos códigos-fonte da aplicação desenvolvida no Bootcamp .NET/Angular.

---

## 📌 Repositórios do Projeto

O projeto é dividido em duas aplicações independentes:

* 🟢 **Back-end (.NET API):** [Acessar Repositório do Back-end](https://github.com/luanaferreirasouza/Projeto-API-dotnet.git)
* 🅰️ **Front-end (Angular):** [Acessar Repositório do Front-end](https://github.com/luanaferreirasouza/produtos-front.git)

*(Substitua `SEU_USUARIO` pelo seu nome de usuário exato no GitHub)*

---

## 🛠️ Tecnologias Utilizadas

* **Back-end:** C#, .NET 8 Web API, Entity Framework Core / SQLite, Swagger, CORS.
* **Front-end:** Angular (Standalone Components), TypeScript, HttpClient, Signals, CSS3.
